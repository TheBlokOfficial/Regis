# shared

Paczka zawierająca wspólny kod infrastrukturalny dla usług monorepo Regis: `ConfigStore` (persystencja JSON), `EventBus` (magistrala zdarzeń pub/sub), `contracts.py` (DTO) oraz `logging.py`. Nie posiada zależności od konkretnych usług.

Pełny opis architektury: [`docs/manifest.md`](../../docs/manifest.md).
